# SHOGUN changelog

- 2026-10-06: first pack. Sources, clock bypass, voice equations, sequencer, tests, and the PDF of the same text.
- 2026-10-06: voice engine. Framework-free C++ in `engine/`, INT and EXT trigger paths, and the named tests in `tests/voices.cpp`.
- 2026-10-06: clock switch pinned under `forge/`. A Trig cable cannot force EXT. Printed 48 kHz rows stay named tests.
- 2026-10-06: placeholder VST3. Flat plate, knobs, levels, a 16-step grid, and TRIG buttons. `make plugin` builds a universal instrument. Panel art stays later.
- 2026-10-07: engine fixes and the web panel. Clock, conga, held-note and tie fixes listed in [BUGS.md](BUGS.md), with tests. `make web` compiles the engine to WebAssembly, checks it against the native build, and writes `web/shogun.html`.
- 2026-10-07: quiet drum voices end at 1e-6. BD1 Dist 0 is a bypass and drive is 9u above it. Main-only centre voices are equal power. Shuffle follows the clock step. Cymbal noise is a fixed mix. The pack states the rest rules, EXT lead and bass, and the CLK IN, RST IN, and RUN IN jacks.
- 2026-10-07: BD1 noise rides the body envelope, so a noisy kick ends with its body. The pan law is equal power: every centre, toms and clap tail included, is 0.707107 on each side.
- 2026-10-07: one decay law for every drum, tau = 8 ms * exp(4.5 u), and a voice is 0 under 1e-3. BD2 at Decay 127 holds; a tom at Decay 127 rings 4 s and ends. The snare bend is its own drop to Tune with an 80 ms floor.
- 2026-10-07: track solo. The soloed voice alone reaches its pair and the main; the others keep running at 0. Mute wins.
- 2026-10-07: a new engine loads the init kit and pattern. STAND-IN knob values set by ear. reset() still clears.
- 2026-10-07: factory patterns and kits cleared for now. The engine, plugin and web page start on INIT, an empty bar, with the INIT kit. New factory content will be written later.
- 2026-10-07: density pass. Shaped bodies (tanh(k sin)) on BD1, BD2, SD, and the toms, BD2 and tom slow FM, a 1 ms BD1 click, SD noise through a ducked 4-pole, six-square metal stacks with a band-pass on the hats and cymbal, and clap bursts fixed at 3 ms with a delayed filtered tail. STAND-IN values set by ear.
- 2026-10-07: Wave on BD1, BD2, and the three toms: a six-cell wave folder on the body oscillator, CC 0 bypass, default CC 32, g 0.5 to 4. Dist stays after Wave. Hats, clap, cymbal, and maracas have no Wave.
- 2026-10-08: **redesign v2.2, first pass** (branch `redesign/shogun`, spec `SHOGUN_Redesign.md` v2.2). The engine is rebuilt per §15.0: host-rate DSP blocks with one oversampling domain (1×/2×/4×, latency 0/23/26), the triple wave shaper (the shared `jidai::dsp::TripleShaper` behind `engine/wave_shaper.h`), new voices, the mod matrix and 4 LFOs, 454 float parameters with `SECTION:LABEL` ids, and the 153-jack bay (§13.2). The plugin runs the engine at the host rate (resampler removed), locks to the host transport, and draws the 8-tab 1200 × 672 panel with rack ears from the spec mockups. The web build compiles the same engine at the AudioContext rate. Numbers in [TESTPLAN.md](TESTPLAN.md). Not yet: room reverb, LANE A/B editor, factory content.
- 2026-10-08: the shared Jidai headers are vendored under `third_party/jidai-common/` (jidai-collection `redesign/jidai` at 9d6e382; see `VENDORED.md`). The JCS detector, pitch and roles, the TripleShaper stages, LevelComp, DcBlocker and the 93-tap halfband come from there. SHAPE, PRE-VCA and the v2.1 migration stay SHOGUN-only in `engine/wave_shaper.h`.
- 2026-10-08: re-vendored jidai-common **1.1.1** (jidai-collection `redesign/jidai` at 24ee621). The wave shaper skips stages with the shared per-block plan, the old HZ/V cables convert with the shared `AliasTable` law (`Lin55ToVoct`), and pitch uses the exact shared `kC3Hz`. Only the alias fan-out (HAT:DECAY, TOM:PITCH) and the three legacy non-R6 names stay in a SHOGUN-side shim.
- 2026-10-08: `make strict` builds the engine, tests, web facade and plugin sources with the JIDAI RACK warning set (JUCE's recommended flags plus `-Wfloat-equal -Wimplicit-int-float-conversion -Wshadow -Wconversion -Wdouble-promotion -Werror`) under clang++ and g++: 0 warnings (was 234 clang++ / 169 g++ sites, including the unused `kNoRing` that failed the macOS build). Output is bit-identical.
- 2026-10-08: **factory bank**. 21 kits, each with its matching pattern, follow INIT (which stays first, with its empty '001 INIT' pattern): Deep Round Kick House, Peak Time Warehouse, Metallic Industrial, Electro Body Pop, Dusty Broken Beat, Head Nod Boom Bap, Minimal Click Groove, Conga Groove, Half Time Pressure, Slow Ballad Brushes, Seven Eight Stepper, Polymeter Drift, Acid Line Workout, Breakbeat Rush, Two Step Shuffle, Lead Arp Sequence, Dub Echo Chamber, Rolling Hat Half Step, Shaker Percussion Circle, Jungle Break Roller and Lo-Fi Tape Wobble. They cover LEAD and BASS lines, the wave shaper, ratchets, flams, probability, micro-timing, p-locks, swing, buses and master, and the mod matrix with the LFOs. The bank is data in one place, `engine/factory.h` with `engine/factory_bank.inc`, stored as saved-state patch documents (`<SHOGUN version=2>` JSON, `SECTION:LABEL` ids, no aliased jacks) and read by one framework-free reader, `engine/patch.h`. The engine, the plugin's program list (`getNumPrograms`/`setCurrentProgram`, so FL Studio can browse it, plus a menu on the KIT and PATTERN displays) and the web page's pattern and kit lists all load it. Every kit with its pattern peaks between -10.47 and -8.00 dBFS over 2 bars at the default master (44.1 and 48 kHz). `make factory` rebuilds the bank. New named tests: `testFactoryPresetsLoad`, `testFactoryRoundTrip`, `testFactoryRenderLevels` and `testFactoryNames` (326 checks), probe checks `programs`, `programs play` and `program state`, and a web parity hash plus a level law for every program.
- 2026-10-08: **no dead panel keys**. Every key on the 8 tabs is bound or removed, and `make panel-check` fails on an unbound one. KIT and PATTERN ◀/▶ step through INIT and the 21 kits with wraparound and ⌕ opens the program list. The ROLL slot is SRC (HOST, INT, EXT; labelled with the current source) and FILL became the CLK IN display. A/B holds two full snapshots (right-click copies the other slot over), and ↶/↷ undo and redo 64 steps of knob moves, step edits and kit loads. The MOD ◉ keys assign a source to the next knob clicked, UI SCALE resizes the window, the OS badge and offline 4× work, RE-ROLL UNIT draws a new tolerance serial, and VELOCITY CURVE shapes MIDI velocity. Removed because nothing backs them: FILL, MUTE GRP, SCENE, MIDI LEARN, MIDI CLOCK OUT, LOCK RND, the LANE A/B editor and its jacks, NOISE FLOOR, TRANSPOSE and SAVE AS DEFAULT. The CC map shows the real fixed table. 9 new probe checks (26).
- 2026-10-08: **web save keeps the whole document**. A pattern saved on the web page is the full patch document, written through the same writer as the plugin (`writePatchJson`, now libc-free for the wasm build) and read with `parsePatch`. Only the fields edited on the page change; probability, micro-timing, ratchets, p-locks, mod rows and the rest of the kit pass through. The LFO tab shows the kit's LFO 1 on its knobs and lists all four LFOs. New tests: `testPatchWriterNoLibc` (330 checks), the `documents` web law, and `web/test_page.mjs` (every program: edit, save, reload, every other field identical).
- 2026-10-08: **user manual**. [docs/manual/SHOGUN_Manual.md](docs/manual/SHOGUN_Manual.md) and its PDF: overview, quick start, every tab with a screenshot, the 151-jack bay with normals, roles and voltages, clock sources and the MIDI note and CC map, the 22 factory programs, DAW setup, specs, troubleshooting, and back-panel patching in the JIDAI RACK with BUSHIDO, RONIN and ORIGAMI. `python3 docs/manual/build_pdf.py docs/manual/SHOGUN_Manual.md` rebuilds the PDF.
- 2026-10-08: re-vendored jidai-common **1.1.2** (jidai-collection `redesign/jidai` at 8a4b5ae). A WAVE stage at amount 0 is now a straight wire at any SYM, and WAVE 0 with the trims at 0 is a full bypass whatever SYM 1 to 3, the SYM matrix rows and VC → SYM are: no ADAA half-sample delay or treble loss, no detector DC block, no LEVEL COMP. The busy-patch golden render hash is unchanged (4feda137ff4c35a9: it has no amount-0 stage with SYM and no HZ/V cable); the same patch with SYM set on amount-0 stages moves from e995ecda8606aaa7 to that same hash, since those SYM settings now do nothing.
