# SHOGUN changelog

- 2026-10-08: **perf-midi: CPU, editor repaint, MIDI out and drag-out, list menus, PLAY transport, fixes A–Q.** Engine CPU (median % of one core, 48 kHz, 256-sample blocks, 2 rounds): idle 6.66 → 2.48, 16 voices busy 19.1 → 13.4, Metallic Industrial playing 19.6 → 15.4, 16 busy + 4 bus comps 25.7 → 20.0; renders bit-identical (render hashes unchanged, golden 4feda137ff4c35a9). Editor: dirty-rect repaint from the 30 Hz timer (only ops whose drawn state changed), static layers cached per tab, the timer slows to 4 Hz while hidden; paint bench mean over tabs 17.6 ms/tick full repaint before → 9.7 ms/tick (about 1 % of the panel area repainted). Every key gives press feedback (held inset, 120 ms flash). MIDI: every played step goes out on a new MIDI output (sample-accurate, with note-offs; drums ch 10 notes 36–49, LEAD ch 1, BASS ch 2; velocity from the accent), and the GRID **DRAG MIDI** key drags the pattern out as a .mid file (hosts need a plugin rescan to see the new output). Right-click on any list opens the full list as a menu with the current item ticked; click steps forward, shift-click back; lists of 10+ open the menu on click; TEMPO, A4, LEN and continuous readouts have value menus. **▶ PLAY** is a labelled transport key (INT start/stop, HOST preview at the host tempo until the host plays, EXT armed) with a run light; the space bar toggles it while SHOGUN has focus and goes to the host while the host plays; Cmd/Ctrl-Z undo, Cmd/Ctrl-Shift-Z or -Y redo. The editor re-anchors at 0,0 after a host collapse/restore or move. VOICE corner lights mute on click (red = activity, green = muted). Help and hint text draws at 9 pt at least and zooms after a 0.5 s hover; popup menus use the plain face. New probe checks (43 in all): program load race, GRID cells, VOICE corner mute lights, editor repaint, PLAY in each SRC mode, keys, host view move / collapse, list controls, step past length, MAIN activity lights, program search, help text, MIDI out, MIDI drag-out. Manual lines updated for these changes only.

- 2026-10-08: **patch writer %.*g test is platform-neutral.** `fmtG` was already correctly rounded (ties to even); Apple's gdtoa leaves trailing zeros on some small integers (305 at precision 2 → `"3.0e+02"` instead of `"3e+02"`), so the old host-`snprintf` check failed on macOS while Linux passed. `testPatchWriterNoLibc` now compares against an embedded correctly-rounded table (`tests/fmtg_ref.inc`, 4459 entries, written by `tools/gen_fmtg_ref.py` and cross-checked with Decimal ROUND_HALF_EVEN) and keeps a regression for that Apple case; host snprintf differences are printed for diagnosis and no longer fail the suite. Factory patch text and the golden render are unchanged (4feda137ff4c35a9). Writer code unchanged.

- 2026-10-08: **build determinism, portable paths, pluginval teardown.** Floating-point contraction is pinned off for every compile (Makefile `FP_FLAGS = -ffp-contract=off` after `CXXFLAGS`; in `plugin/CMakeLists.txt` on the engine, plugin and probe targets; MSVC `/fp:precise`, clang-cl also `-ffp-contract=off`). The golden render is 4feda137ff4c35a9 with g++ and clang++, by default and with `-mfma -ffp-contract=fast` (or clang++ `=on`, or `-march=native`) forced on in front of the off flag, and the test log is identical in every case. The engine warning flags are guarded by compiler: GCC/Clang keep `-Wall -Wextra -Werror`, MSVC gets `/W4` (no `/WX`, not yet built with MSVC) and `_CRT_SECURE_NO_WARNINGS`. JUCE is found at `JUCE_DIR` (default `../JUCE`; `JUCE_SRC`/`JUCE_LINUX` still work; `JUCE_DIR=fetch` downloads 8.0.4) and make stops with a clear message when it is missing; GraphForge defaults to `../graphforge/src`, the VST3 link folder is `VST3_INSTALL_DIR`. Machine-specific paths are gone from the tests and docs. pluginval 1.0.4 (in-process, level 10) sometimes crashes after SUCCESS: that is a use-after-free in pluginval's JUCE VST3 host (its event loop calls a plugin-socket callback after the host's run loop was freed), not SHOGUN code; see TESTPLAN.md, "pluginval teardown crash". Hardening, not the fix for that crash: processBlock no longer posts a message for a GLOBAL:OS change (a 10 Hz message-thread timer re-prepares), and the MOD matrix popup menus no longer keep a raw pointer to the panel.

- 2026-10-08: **LEAD/BASS CV AMT, MOD matrix to 32 rows, SRC as an instance setting.** The ROUTE CV AMT knob for LEAD and BASS now scales the pitch CV into the voice: NOTE (trigger and held paths, after Lin55ToVoct for an old HZ/V cable) and V/OCT, with 1.0 = exact 1 V/oct (the default, so presets and the golden render stay identical). The MOD tab matrix no longer stops at ten rows: used slots plus "+ add" scroll (mouse wheel = one row, ▲ ▼ = one page of ten) so every row up to all 32 is reachable, editable and removable. The web page has no MOD matrix UI (mod rows pass through the mirror). CLOCK:SOURCE is an instance setting as on the rack: loading a factory program, INIT PATCH and A/B keep HOST / INT / EXT; a preset's CLOCK:SOURCE is ignored; undo and host save/restore still restore it. New tests: `testSynthCvAmtNote` (30 checks, 372 named), probe `matrix 32 rows` and `SRC on program load` (28 probe checks). Manual (24 pages), TESTPLAN and the Design Pack PDF updated. Golden render unchanged (4feda137ff4c35a9).

- 2026-10-07: quiet drum voices end at 1e-6. BD1 Dist 0 is a bypass and drive is 9u above it. Main-only centre voices are equal power. Shuffle follows the clock step. Cymbal noise is a fixed mix. The pack states the rest rules, EXT lead and bass, and the CLK IN, RST IN, and RUN IN jacks.
- 2026-10-07: BD1 noise rides the body envelope, so a noisy kick ends with its body. The pan law is equal power: every centre, toms and clap tail included, is 0.707107 on each side.
- 2026-10-07: one decay law for every drum, tau = 8 ms * exp(4.5 u), and a voice is 0 under 1e-3. BD2 at Decay 127 holds; a tom at Decay 127 rings 4 s and ends. The snare bend is its own drop to Tune with an 80 ms floor.
- 2026-10-07: track solo. The soloed voice alone reaches its pair and the main; the others keep running at 0. Mute wins.

- 2026-10-08: **redesign v2.2, first pass** (branch `redesign/shogun`, spec `SHOGUN_Redesign.md` v2.2).
